# _inbox — you → Claude

Drop things here for Claude to use: sample photos, Figma exports, reference
documents, screenshots, PDFs, anything you want me to look at or work from.

How it works:
- You add files here; tell me what they are and what you want done.
- I read from here, then move anything worth keeping into its permanent home
  (e.g. `samplePhotos/`, `docs/`, or the spec) and leave the rest for you to clear.
- Contents are **gitignored** (except this README) — treat it as a scratch drop
  zone, not storage.

Current residents:
- `figma-exports/` — Figma PNG snapshots. Transient; the Figma file is the live
  source (use the Figma MCP).
