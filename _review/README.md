# _review — Claude → you

Things I've made for you to look at and react to: HTML mockups for design
decisions, draft/temp Markdown, side-by-side options, generated previews.

How it works:
- I put work-in-progress or decision artifacts here and point you to them.
- Once you've decided, the keeper moves to its real home (`docs/designs/`, the
  spec, etc.) and the rest can be cleared.
- Contents are **gitignored** (except this README) — transient by design.

Current residents:
- `mockups/` — HTML design prototypes (jukebox grid, nav bar, transport buttons,
  today school data, vinyl spin). Reference for past design decisions.
- `layout-editor/` — the layout editor and the data-driven Entry renderer
  (2026-09-24), see its README.
- `entry/` — the Entry board and its dashboard cards (2026-09-24).
- `echo/` — Echo Show verification screenshots at 1280x800 (2026-09-24), see
  its README.
- `settings-tweaker.html` — Mac-only scratchpad for iterating on Settings
  typography + spacing (not part of the kiosk build).
